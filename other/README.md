# Other

This repository serves as a central place for supplementary artifacts that do not belong in the main `marketplace_platform` codebase.

## Purpose

The goal of this repo is to collect and organize supporting materials such as:

- Documentation
- Architecture diagrams
- PlantUML scripts
- Markdown guidelines (e.g., branching strategy, workflows)
- Notes, drafts and exploratory work
- Any auxiliary code or assets not part of the production system

## Scope

If something does not directly belong to the application codebase (`marketplace_platform`), it should likely live here instead.

Examples:
- High-level system design diagrams
- ADRs (Architecture Decision Records)
- Development guidelines
- Infrastructure notes
- Experimental or reference implementations

## Structure

The repository is intentionally flexible, but a suggested structure is:
- `/docs` - General documentation  
- `/diagrams` - PlantUML and other diagrams  
- `/guidelines` - Development practices (branching, code standards)  
- `/experiments` - Prototypes or exploratory work
